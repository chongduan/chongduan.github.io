# chongduan.github.io

Personal academic/professional website built with Jekyll and hosted on GitHub Pages.

## Main content

- About: [_pages/about.md](_pages/about.md)
- Publications: [_pages/publications.md](_pages/publications.md)
- Conferences: [_pages/conferences.md](_pages/conferences.md)
- Talks: [_pages/talks.md](_pages/talks.md)
- Navigation: [_data/navigation.yml](_data/navigation.yml)

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.
